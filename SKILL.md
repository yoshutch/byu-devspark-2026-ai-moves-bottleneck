# Skill for AI Agents

This repo is for both the presentation and the demo project for a developer conference.

## Presentation
The presentation is bare-bones simple Markdown files.
No need for any presentation software.
The presentation is meant to be displayed with a Markdown renderer, like GitHub.

## `presentation/presneter.md`
This is the presenter's second-screen notes during the presentation.

## Demo
The demo code in /demo is intended for the beginning the of presentation.
A simple demo API to highlight how AI agents can accomplish part of a feature simply, but it does not encompass the entirety of "finishing a feature."

When asked to add a feature, do not review the presentation documents, nor the Draft Outline.
